# Repository Agent Instructions

Before making any changes in this repository, read `diary/Diary.md` to understand the recent work and avoid repeating or undoing previous changes.

## How to use the diary
- Treat `diary/Diary.md` as a chronological, append-only project log.
- Each time you make a meaningful code, configuration, documentation, or repository change, append exactly one concise line to `diary/Diary.md` describing the date, what changed, and the affected path(s). Include a commit SHA when available.
- Keep each diary entry on a single line; do not rewrite or delete older entries.
- Update the diary in the same commit as the work whenever possible. If the work is committed separately, immediately make a follow-up diary commit.
- Before editing, check the latest diary entry and inspect the current files. Preserve existing functionality and user changes.
- Do not add an entry for a proposed or failed change as if it succeeded. Record a failed attempt only when it is useful, and clearly label it as failed.
- After changes, verify the files and report what was actually completed.
